# Assets Folder

This folder contains static assets used throughout the application.

## Adding the BYD Background Image

1. **Add your BYD car image** to this folder with the filename: `byd-background.jpg`

2. **Image Requirements:**
   - Filename: `byd-background.jpg`
   - Format: JPG, PNG, or WebP
   - Recommended size: 1200px width or higher
   - The image will be used on the home page with a blue overlay effect

3. **Path in CSS:**
   - The image is referenced in `src/styles/HomePage.css` as `/src/assets/byd-background.jpg`
   - Once you add the image file, it will automatically display on the home page

## Example File Structure

```
src/assets/
└── byd-background.jpg    ← Add your BYD image here
```

The home page will display your BYD background image with a beautiful fade-in welcome message on top of it!
